## 🛠️ Utilisation

1. Copiez l'URL du flux souhaité dans le tableau ci-dessus.
2. Ouvrez votre lecteur RSS préféré
3. (**Read You**, **Feeder**, **Inoreader**, **NetNewsWire**, etc.).
4. Ajoutez un nouveau flux
5.  et collez l'URL.
